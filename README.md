There's nothing much to this one. I made a project that runs a fragment shader on an entire window. What's worth studying are the shaders in the exmaple folder. My commits will simply add more examples, no changes to the main file will be made.

## Usage
- Run `make` to create the `screenShade` executable.
- While in the project directory, run `.screenShade <path to a fragment shader>` to open a window that has the shader.
- Press Space to refresh.

## Dependencies
- GLFW

## Requirements
- Linux
